# RentLeaks

Flexible housing marketplace for rooms, co-living, furnished apartments, 1-month+ stays, and lease-breaks. Markets: the United States and Canada plus major cities in the UK, Ireland, France, Spain, the Netherlands, Switzerland, Germany, and Italy.

The public site is static HTML at the repo root. `web/` is the Next.js app layer.

Minimum stay is 30 days. Prices are All-in.
